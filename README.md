# Sistema de Gestión de Usuarios

## Descripción

Aplicación de consola desarrollada en Python para gestionar registros de usuarios. Permite realizar operaciones CRUD, buscar información y trabajar con datos almacenados en archivos JSON.

El proyecto sirve como práctica de estructuras de datos, manejo de archivos y organización de la lógica de una aplicación.

## Funcionalidades

- **Crear:** registrar nuevos usuarios.
- **Consultar:** visualizar los usuarios registrados.
- **Actualizar:** modificar la información de los registros.
- **Eliminar:** eliminar usuarios.
- **Buscar:** localizar usuarios mediante los criterios disponibles en la aplicación.
- **Almacenamiento JSON:** guardar y recuperar información desde archivos.
- **Exportación a Excel:** exportar los registros para facilitar su consulta y análisis.

## Tecnologías utilizadas

- Python
- Diccionarios y listas
- Archivos JSON
- Manejo de archivos
- Exportación de datos a Excel

## Requisitos

- Python instalado.
- Las dependencias necesarias para la exportación a Excel, si el proyecto utiliza bibliotecas externas.

## Instalación y ejecución

Clona el repositorio:

```bash
git clone https://github.com/Ale3241/Lista_de_usuarios.git
cd Lista_de_usuarios
```

Ejecuta el archivo principal del proyecto:

```bash
python nombre_del_archivo.py
```

**Nota:** reemplaza `nombre_del_archivo.py` por el nombre real del archivo principal. Si el proyecto utiliza dependencias externas, instala las indicadas en sus archivos de configuración o documentación.

## Almacenamiento de datos

La aplicación utiliza archivos JSON para conservar los registros entre ejecuciones.

Evita incluir datos personales reales en los archivos de ejemplo o en el repositorio público.
